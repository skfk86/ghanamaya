## ما تغيّر (السلوك محفوظ)
1. **سباق المغادرة أثناء التحميل (خطأ حقيقي):** الشاشات التي تنتظر الشبكة كانت ترسم فوق الشاشة التالية إن رجع المستخدم قبل انتهاء التحميل، وكانت المحادثة تترك مستمعاً حياً بعد مغادرتها. الحل: رمز شاشة (`S.nav`) يتغيّر مع كل انتقال (`leaveScreen`)، وكل شاشة غير متزامنة (10 شاشات) تتحقق منه قبل الرسم وقبل ربط المستمع. ثلاثة اختبارات انحدار تفشل على الكود القديم وتنجح على الجديد.
2. **CSS ميت:** حُذف 89 تعريفاً و6 قواعد فارغة يلغيها دائماً تعريف لاحق للمحدد نفسه (37→35 KB). مقارنة النمط المحسوب لـ 3,792 عنصراً في 24 حالة (12 شاشة × فاتح وداكن): صفر فروق.
3. **معالجة الأخطاء:** `showError(e)` واحدة بدل 33 نسخة من `toast(errMsg(e), 'error')`.
4. **كود ميت:** حُذف `loadListings` بعد التحقق من عدم وجود أي استدعاء مباشر أو نصي أو ديناميكي.

لم يتغيّر: منطق الأعمال، شكل قاعدة البيانات، الروابط العميقة، التخزين المحلي، وضع عدم الاتصال، إشعارات FCM، مسارات الملفات والبناء.

## تقسيم الملف الواحد: مدروس ومؤجَّل عن قصد
Capacitor يقبل وحدات ES محلية (`<script type="module" src="app/…">`) بلا مشكلة. ما يمنع التقسيم الآن ثلاثة أشياء تعتمد على أن الكود داخل `index.html`:
- اختبارات الواجهة تحقن بيانات التجربة وFirebase الوهمي باستبدال نصي داخل `index.html`، وتحمّل الصفحة من `tests/ui/` (المسارات النسبية تتغير).
- خطوة البناء تعيد كتابة روابط Firebase والخط داخل `index.html` فقط.
- `mawashi-kit/setup/apply.mjs` يستبدل الرموز في كل الملفات (يعمل)، لكن صفحة البيع والاختبارات تفترض ملفاً واحداً.

الخطة عند التنفيذ، بالترتيب، مع تشغيل كل الاختبارات وبصمة الأنماط بعد كل خطوة:
1. `www/app.css` أولاً (أبسط: لا منطق)، مع `<base href>` في صفحات الاختبار.
2. `www/app/core.js` (الحالة، الأدوات، Firebase)، ثم ملف لكل مجموعة شاشات (السوق، المحادثات، الطلبات، المحفظة، البائع).
3. تعديل خطوة البناء لتعيد كتابة الاستيرادات في كل `www/**/*.js`.

## أدوات الانحدار

```bash
bash tests/run.sh                                  # 266 اختبار سيرفر
node tests/ui/flow.js www/index.html               # 62 مساراً
node tests/ui/uitest.js www/index.html             # أحجام اللمس والتمرير (فاتح/داكن)
node tests/ui/styles.js www/index.html before.json # بصمة الأنماط قبل التعديل
node tests/ui/styles.js www/index.html after.json  # بعده
node tests/ui/style-diff.js before.json after.json # لا فروق = لا تغيير مرئي
```
(`NODE_PATH=$(npm root -g)` لاختبارات الواجهة.)
